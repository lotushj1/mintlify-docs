## 官方與高品質路線

這些平台經過審核或由官方維護，品質較有保障。

<CardGroup cols={2}>
  <Card title="Claude Skills Library (MCP)" icon="circle-check" href="https://mcpservers.org/claude-skills">
    **Claude 官方技能庫**

    收錄文件處理、開發工具、創意設計等完整 Skills。如果你主要使用 Claude，這是最穩定的選擇。
  </Card>
  <Card title="Skills Directory" icon="shield-check" href="https://skillsdirectory.com/">
    **官方認可的註冊中心**

    收錄經過審核的高品質 Skills，支援 Vercel 部署。適合企業用戶或對安全性有要求的開發者。
  </Card>
  <Card title="Skillstore" icon="badge-check" href="https://skillstore.io/zh-hans">
    **安全審計的技能市場**

    提供一鍵安裝、品質驗證，包含程式碼審查、文件、測試等分類。介面清楚好操作。
  </Card>
</CardGroup>

## 使用建議

<Steps>
  <Step title="新手從官方庫開始">
    剛開始使用 Skill 的話，建議從 **Claude Skills Library** 或 **Skillstore** 開始，這些平台的 Skill 品質較穩定。
  </Step>
  <Step title="先搜尋再製作">
    想自己做 Skill 之前，先到這些資源網站用關鍵字搜尋，看看是否已經有人做過類似的功能。
  </Step>
  <Step title="注意評級和使用人數">
    安裝前建議看一下評級、星星數和使用人數，這些指標可以幫助你判斷品質。
  </Step>
  <Step title="企業選擇有審核的平台">
    如果是企業使用，建議選擇有審核機制的平台（如 Skills Directory），確保安全性。
  </Step>
</Steps>

## 如何挑選合適的 Skill

<AccordionGroup>
  <Accordion title="看使用人數和評價">
    使用人數多、評價好的 Skill 通常比較可靠。不過也要注意，有些新的好 Skill 可能還沒被很多人發現。
  </Accordion>

  <Accordion title="檢查更新頻率">
    最近有更新的 Skill 通常維護得比較好。如果一個 Skill 很久沒更新，可能會有相容性問題。
  </Accordion>

  <Accordion title="閱讀說明文件">
    好的 Skill 會有清楚的說明文件，包括：
    - 功能介紹
    - 使用方式
    - 參數說明
    - 使用範例
  </Accordion>

  <Accordion title="檢視原始碼（進階）">
    如果你有技術背景，可以看一下 Skill 的原始碼，確認它做的事情符合你的預期。
  </Accordion>
</AccordionGroup>
