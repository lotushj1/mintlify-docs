## 通用的 Skill 使用方式

不論你使用哪種工具，Skill 的基本使用方式都是相同的：

### 基本語法

```
/skill名稱
```

### 帶參數

```
/skill名稱 參數
```

### 常用範例

| 指令 | 功能 |
|-----|------|
| `/commit` | 自動提交程式碼 |
| `/review-pr 123` | 審查編號 123 的 PR |
| `/help` | 查看可用的 Skill |
