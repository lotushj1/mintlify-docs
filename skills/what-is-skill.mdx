## Skill 是什麼？

**Skill** 是 Claude Code 中的「快捷指令」功能。你可以把它想像成一個預先設定好的工作流程——只要輸入簡單的指令，Claude 就會自動執行一系列複雜的任務。

<Info>
**簡單來說**：Skill 就像是你手機上的捷徑功能，一鍵就能完成多個步驟。
</Info>

---

## 生活化的比喻

想像一下你每天早上都要做以下事情：
1. 打開電腦
2. 檢查信箱
3. 開啟工作軟體
4. 查看今天的待辦事項

如果有一個按鈕可以**一鍵完成所有步驟**，是不是很方便？

**Skill 就是這樣的概念**——它幫你把一連串的操作打包成一個簡單的指令。

---

## 為什麼要使用 Skill？

| 沒有使用 Skill | 使用 Skill 後 |
|--------------|-------------|
| 每次都要重複輸入相同的指令 | 一個指令完成所有步驟 |
| 容易忘記某些步驟 | 確保每次都執行完整流程 |
| 需要記住複雜的操作順序 | 簡化為易記的短指令 |
| 花費大量時間在重複工作上 | 節省時間，專注在重要的事情上 |

## 誰適合使用 Skill？

Skill 設計給**所有人**使用，不論你是：

- **完全沒有程式背景的新手**：使用現成的 Skill 來完成工作
- **有一點經驗的使用者**：修改現有 Skill 來符合自己的需求
- **進階使用者**：建立自己的 Skill 來自動化複雜的工作流程
