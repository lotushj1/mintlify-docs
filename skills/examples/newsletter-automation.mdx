這個範例會教你建立一個**自動化電子報系統** Skill，它可以幫你：
- 自動蒐集特定主題的最新資訊
- 整理並篩選重要內容
- 生成排版好的電子報內容

## 完成後的效果

只要輸入一個指令：

```
/newsletter 本週 AI 新聞
```

Claude 就會自動：
1. 蒐集本週的 AI 相關新聞
2. 篩選出最重要的 5-10 則
3. 為每則新聞撰寫摘要
4. 生成排版好的電子報內容

---

## 建立步驟

### 步驟 1：建立 Skill 檔案

在你的專案中建立 `.claude/skills/newsletter.md` 檔案：

```
你的專案/
├── .claude/
│   └── skills/
│       └── newsletter.md    ← 建立這個檔案
└── 其他檔案...
```

### 步驟 2：撰寫 Skill 內容

將以下內容複製到 `newsletter.md`：

```markdown
---
description: 自動生成電子報內容
---

請幫我製作一份電子報，主題是：$ARGUMENTS

## 執行步驟

### 1. 資料蒐集
- 搜尋該主題最近一週的重要新聞和更新
- 找出 5-10 則最具代表性的內容
- 確保來源可靠且資訊正確

### 2. 內容篩選
篩選標準：
- 對讀者有實際幫助
- 具有時效性
- 內容具有深度或獨特觀點

### 3. 撰寫摘要
為每則新聞撰寫：
- 標題（吸引人但不誇張）
- 50-100 字的摘要
- 為什麼這則新聞重要

### 4. 生成電子報

請使用以下格式輸出：

---

# 📬 [主題] 週報

> 本週精選 [數量] 則重要更新

## 本週焦點

[最重要的 1-2 則新聞，詳細說明]

## 快速瀏覽

[其他新聞的簡短摘要列表]

## 編輯觀點

[對本週趨勢的簡短分析，2-3 句話]

---

### 5. 格式要求
- 使用繁體中文
- 語氣專業但平易近人
- 適當使用 emoji 增加可讀性
- 每段落之間要有適當的空白
```

### 步驟 3：測試你的 Skill

儲存檔案後，在 Claude 中輸入：

```
/newsletter 本週科技新聞
```

或指定更具體的主題：

```
/newsletter 本週 AI 產業動態
```

## 進階自訂

### 自訂電子報風格

你可以修改 Skill 中的格式要求來調整風格：

<Tabs>
  <Tab title="專業正式">
    ```markdown
    ### 格式要求
    - 使用正式書面語
    - 避免使用 emoji
    - 引用具體數據和來源
    ```
  </Tab>
  <Tab title="輕鬆活潑">
    ```markdown
    ### 格式要求
    - 使用輕鬆口語化的語氣
    - 適當使用 emoji 和比喻
    - 加入有趣的小知識
    ```
  </Tab>
  <Tab title="極簡風格">
    ```markdown
    ### 格式要求
    - 每則新聞限制在 30 字內
    - 使用條列式呈現
    - 省略分析和觀點
    ```
  </Tab>
</Tabs>

### 加入固定欄位

如果你的電子報有固定欄位，可以在 Skill 中加入：

```markdown
### 6. 固定欄位

在電子報最後加入：

## 📅 近期活動
[搜尋相關的近期活動或研討會]

## 📚 推薦閱讀
[推薦 2-3 篇深度文章]

## 💬 讀者回饋
[留下回饋的方式，例如 email 或表單連結]
```

### 指定資料來源

如果你有偏好的資料來源，可以加入：

```markdown
### 1. 資料蒐集
優先參考以下來源：
- TechCrunch
- The Verge
- 數位時代
- iThome

如果這些來源沒有足夠資訊，再擴展到其他可靠媒體。
```

## 常見問題

<AccordionGroup>
  <Accordion title="為什麼生成的內容不夠新？">
    Claude 的知識有截止日期，如果需要最新資訊，可以：
    - 搭配網路搜尋工具（如 MCP）使用
    - 提供你已經蒐集的新聞連結讓 Claude 整理
  </Accordion>

  <Accordion title="可以自動發送電子報嗎？">
    這個 Skill 負責生成內容，發送需要搭配其他工具：
    - 可以將生成的內容複製到 Mailchimp、Substack 等平台
    - 進階用戶可以結合 API 實現自動發送
  </Accordion>

  <Accordion title="如何讓每次生成的風格一致？">
    在 Skill 中加入具體的風格範例：
    ```markdown
    ### 風格範例
    以下是標題的寫法範例：
    - ✅ 好的標題：「OpenAI 發布重大更新，三大功能一次看」
    - ❌ 避免的標題：「震驚！AI 即將取代人類？」
    ```
  </Accordion>
</AccordionGroup>
