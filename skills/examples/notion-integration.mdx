## 這個教學適合誰？

這份教學是為**完全沒有程式背景的人**設計的。如果你符合以下情況，這份教學非常適合你：

- 你經常需要整理會議紀錄，但覺得手動整理很花時間
- 你已經在使用 Notion 管理工作，想要讓流程更自動化
- 你聽過 AI 可以幫忙做事，但不知道怎麼開始

<Info>
**完成這個教學後，你將能夠：**
1. 錄完會議後，只要告訴 AI 音檔在哪裡
2. AI 會自動把錄音轉成文字、整理成漂亮的會議紀錄
3. 會議紀錄會自動出現在你的 Notion Database 中

整個過程你只需要說一句話，剩下的全部自動完成！
</Info>

## 什麼是 Skill？為什麼需要它？

在開始之前，讓我們先了解一個重要的概念：**Skill**。

<Note>
**簡單來說，Skill 就像是你教給 AI 的「標準作業流程」（SOP）。**

想像你有一位新助理，你需要教他怎麼整理會議紀錄。你會告訴他：
- 會議紀錄要包含哪些項目（日期、參與者、討論內容...）
- 格式應該長什麼樣子
- 整理完要存到哪裡

Skill 就是把這些指示寫下來，讓 AI 每次都能用同樣的方式幫你處理。
</Note>

### Skill 的好處

| 沒有 Skill | 有 Skill |
|-----------|---------|
| 每次都要重新解釋你要什麼格式 | 只要說「用 XX Skill 處理」就好 |
| AI 的輸出可能每次都不一樣 | 每次都會產出一致的格式 |
| 需要花時間檢查和調整 | 結果符合你的需求，省下大量時間 |

## 開始建立：會議紀錄自動化系統

現在讓我們開始建立會議紀錄的自動化系統。這個系統會幫你：

1. **語音轉文字**：把會議錄音變成文字
2. **智慧整理**：把雜亂的對話整理成結構化的紀錄
3. **自動儲存**：直接存到你的 Notion Database

### 需要準備的工具

<Info>
**本教學會使用到的工具：**
- **OpenAI Whisper API** - 這是 OpenAI 提供的語音轉文字服務，可以把錄音變成文字
- **Claude** - AI 助手，負責整理會議內容
- **Notion** - 你的筆記和資料庫工具

別擔心，下面會一步步教你怎麼設定這些工具。
</Info>

## 第一步：申請必要的 API Key

<Note>
**什麼是 API Key？**

API Key 就像是一把「鑰匙」，讓不同的軟體可以互相溝通。當 Claude 想要使用 Whisper 的語音轉文字功能時，需要用這把鑰匙來證明「我有權限使用這個服務」。

你可以把它想像成：你辦了一張會員卡，有了這張卡，店員才會提供服務給你。
</Note>

### 1. 申請 OpenAI API Key（給 Whisper 使用）

Whisper 是 OpenAI 公司提供的語音轉文字服務，我們需要先申請一個帳號。

<Steps>
  <Step title="前往 OpenAI 平台">
    前往 [OpenAI Platform](https://platform.openai.com/) 並登入或註冊帳號

    如果你已經有 ChatGPT 帳號，可以直接用同一個帳號登入。
  </Step>
  <Step title="進入 API Keys 頁面">
    點擊右上角的個人頭像 → **View API Keys**

    或直接前往：https://platform.openai.com/api-keys
  </Step>
  <Step title="建立新的 API Key">
    1. 點擊 **Create new secret key**
    2. 輸入名稱，例如「Whisper 語音轉文字」（這只是方便你記得這個 Key 是做什麼用的）
    3. 點擊 **Create secret key**
    4. **立即複製並保存** API Key（它只會顯示這一次！）

    <Warning>
    **非常重要**：這個 Key 只會顯示一次！請立刻複製到安全的地方（例如密碼管理器）。
    如果沒有保存就關掉頁面，你需要刪除這個 Key 再建立一個新的。
    </Warning>
  </Step>
  <Step title="設定付費方式">
    Whisper API 是付費服務，需要綁定信用卡：

    1. 前往 **Settings** → **Billing**
    2. 點擊 **Add payment method**
    3. 新增信用卡資訊

    <Info>
    **費用其實很便宜**：
    - 10 分鐘的錄音：約 $0.06 美元（約台幣 2 元）
    - 1 小時的錄音：約 $0.36 美元（約台幣 11 元）

    一般會議錄音的費用大約就是一杯飲料錢，但可以省下你大量的整理時間！
    </Info>
  </Step>
</Steps>

### 2. 設定 Notion Integration

接下來，我們要讓 Claude 能夠存取你的 Notion。這需要建立一個「Integration」（你可以把它想成是「讓外部程式連接 Notion 的通道」）。

<Steps>
  <Step title="前往 Notion 開發者頁面">
    前往 [Notion Developers](https://www.notion.so/my-integrations) 並登入你的 Notion 帳號
  </Step>
  <Step title="建立新的 Integration">
    1. 點擊 **New integration**
    2. 輸入名稱，例如「會議紀錄助手」
    3. 選擇要連接的 Workspace（如果你有多個工作區，選擇你要存放會議紀錄的那個）
    4. 點擊 **Submit** 建立
  </Step>
  <Step title="複製 API Token">
    建立完成後，你會看到一串以 `secret_` 開頭的文字，這就是你的 Token。請複製並保存起來。
  </Step>
  <Step title="授權 Integration 存取頁面">
    **這一步很重要！** Integration 建立後，預設是沒有權限存取任何頁面的。你需要手動授權：

    1. 開啟你想要存放會議紀錄的 Notion 頁面
    2. 點擊右上角的 **...** 選單
    3. 選擇 **Connections** → **Connect to** → 選擇你剛建立的「會議紀錄助手」

    <Warning>
    如果跳過這一步，AI 會告訴你「無法存取 Notion」。記得要授權！
    </Warning>
  </Step>
</Steps>

## 第二步：建立 Notion 會議紀錄 Database

現在我們要在 Notion 中建立一個專門存放會議紀錄的 Database。

<Note>
**什麼是 Database？**

Notion 的 Database 就像是一個 Excel 表格，但功能更強大。你可以用它來整理和篩選資料。
在這個教學中，我們會用 Database 來管理所有的會議紀錄，方便你按日期、參與者或狀態來查找。
</Note>

### 步驟 1：建立 Page 並授權

<Steps>
  <Step title="建立新的 Page">
    在 Notion 中建立一個新的 Page，命名為「會議紀錄」或任何你喜歡的名稱
  </Step>
  <Step title="授權 Integration 存取">
    1. 點擊頁面右上角的 **...** 選單
    2. 選擇 **Connections**
    3. 點擊 **Connect to** → 選擇「會議紀錄助手」

    <Warning>
    **一定要完成這一步！** 沒有授權的話，AI 無法在這個頁面建立或編輯任何內容。
    </Warning>
  </Step>
  <Step title="取得 Page ID">
    複製頁面的網址，網址格式類似：
    ```
    https://www.notion.so/你的工作區/會議紀錄-abc123def456...
    ```

    最後面那串亂碼（`abc123def456...`）就是 Page ID，請記下來備用。

    <Tip>
    不確定哪一段是 Page ID？把整個網址複製給 AI，它會幫你找出來。
    </Tip>
  </Step>
</Steps>

### 步驟 2：讓 AI 幫你建立 Database

這是最輕鬆的部分！你只需要複製以下文字，貼到 Claude 對話框中：

```text
請在我的 Notion 頁面中建立一個會議紀錄 Database。

Page ID：[貼上你的 Page ID]

Database 需要包含以下欄位：
1. 標題（Title）：會議主題
2. 日期（Date）：會議日期
3. 參與者（Multi-select）：參與人員
4. 狀態（Select）：待整理 / 已完成 / 需追蹤
5. 摘要（Text）：會議摘要
6. 待辦事項（Text）：行動項目清單
7. 會議內容（Text）：完整的會議紀錄

請建立這個 Database，並將 Database ID 告訴我。
```

<Tip>
**AI 會幫你做什麼？**
1. 在你指定的頁面建立一個 Database
2. 設定好所有欄位
3. 告訴你 Database ID（後面會用到）

你只需要等待幾秒鐘，就能得到一個格式完美的 Database！
</Tip>

### Database 欄位說明

| 欄位名稱 | 類型 | 用途說明 |
|---------|------|---------|
| 會議主題 | Title | 這是 Database 的標題欄位，會顯示在列表第一欄 |
| 日期 | Date | 記錄會議是哪一天舉行的，方便按時間排序 |
| 參與者 | Multi-select | 可以選擇多位參與者，之後可以篩選「某人參加過的所有會議」 |
| 狀態 | Select | 追蹤這份紀錄的處理狀態（例如：還沒整理完、已完成、有事項需要追蹤） |
| 摘要 | Text | 簡短的會議重點，讓你快速了解這場會議在討論什麼 |
| 待辦事項 | Text | 會議中決定要做的事情，方便追蹤執行進度 |
| 會議內容 | Text | 完整的結構化會議紀錄 |

## 第三步：建立會議紀錄 Skill

現在我們要建立最重要的部分：一個可以自動處理會議錄音的 Skill。

### 使用提示詞快速建立

複製以下內容，貼到 Claude 對話框中：

```text
請幫我在專案中建立一個 Skill，用來處理會議錄音並自動儲存到 Notion。

請在 .claude/skills/ 資料夾中建立 meeting-to-notion.md 檔案。

這個 Skill 的功能：
1. 接收音檔位置
2. 使用 Whisper API 將音檔轉換成文字
3. 整理成結構化的會議紀錄（包含：會議摘要、討論議題、關鍵決策、待辦事項）
4. 自動儲存到我的 Notion Database

我的 Notion Database ID 是：[貼上你的 Database ID]

請幫我建立這個 Skill，並確保它會自動完成所有步驟。
```

<Note>
**Skill 建立完成後會發生什麼？**

以後你只需要說：
```
/meeting-to-notion

音檔位置：~/Downloads/meeting.mp3
```

AI 就會自動完成：錄音轉文字 → 整理成會議紀錄 → 存到 Notion。

整個過程大約只需要幾分鐘（取決於錄音長度），而且你完全不需要做任何事！
</Note>

## 第四步：實際使用

恭喜你完成了所有設定！現在讓我們來測試一下。

### 完整操作流程

<Steps>
  <Step title="錄製會議">
    使用手機或電腦錄製會議。小技巧：
    - 儘量在安靜的環境錄音
    - 請參與者說話時靠近麥克風

    （把路徑換成你實際的檔案位置）
  </Step>
  <Step title="等待處理完成">

    1. 讀取音檔
    2. 轉換成文字（這步可能需要幾分鐘）
    3. 整理成會議紀錄格式

  </Step>
  <Step title="確認結果">

  </Step>
</Steps>

## 進階設定：讓 AI 直接操作 Notion

如果你想要更順暢的體驗，可以安裝 Notion MCP Server。這會讓 AI 能夠直接讀寫你的 Notion，不需要透過其他方式。

<Note>
**什麼是 MCP Server？**

MCP（Model Context Protocol）是一種讓 AI 連接外部工具的技術。安裝了 Notion MCP Server 之後，Claude 就可以直接操作你的 Notion，就像它有了一雙可以操作 Notion 的手。
</Note>

### 安裝步驟

<Steps>
  <Step title="開啟 Claude 設定">
    找到 Claude 的設定檔案（通常在專案根目錄的 `.claude` 資料夾中）
  </Step>
  <Step title="加入 Notion MCP Server 設定">
    在設定中加入以下內容：

    ```json
    {
      "mcpServers": {
        "notion": {
          "command": "npx",
          "args": ["-y", "@notionhq/notion-mcp-server"],
          "env": {
            "OPENAPI_MCP_HEADERS": "{\"Authorization\": \"Bearer secret_你的Token\", \"Notion-Version\": \"2022-06-28\"}"
          }
        }
      }
    }
    ```

    把 `secret_你的Token` 換成你在第一步取得的 Notion Integration Token。
  </Step>
  <Step title="重新啟動 Claude">
    設定完成後重新啟動 Claude，讓設定生效。
  </Step>
</Steps>

<Tip>
安裝完成後，AI 就可以直接在 Notion 中建立頁面、編輯內容，完全不需要你手動操作！
</Tip>

## 常見問題

<AccordionGroup>
  <Accordion title="AI 說無法存取 Notion，怎麼辦？">
    這通常是因為沒有授權。請確認：

    1. **Notion Integration 有建立嗎？**
       - 前往 https://www.notion.so/my-integrations 確認

    2. **頁面有授權給 Integration 嗎？**
       - 開啟 Notion 頁面 → 點擊右上角 ... → Connections
       - 確認你的 Integration 有出現在列表中

    3. **Token 正確嗎？**
       - 確認 MCP Server 設定中的 Token 沒有打錯

    4. **有重新啟動 Claude 嗎？**
       - 修改設定後需要重新啟動才會生效
  </Accordion>

  <Accordion title="語音轉文字的結果不太準確？">
    幾個改善建議：

    - **錄音品質**：儘量在安靜的環境錄音，避免背景噪音
    - **說話清晰**：請參與者說話速度適中，發音清楚
    - **麥克風距離**：說話者靠近麥克風效果會更好
    - **專有名詞**：如果有特殊的專有名詞（公司名、產品名），可以在 Skill 中加入修正規則
  </Accordion>

  <Accordion title="音檔太大無法處理？">
    Whisper API 限制單一檔案最大 25MB。如果你的檔案太大：

    **方法一：壓縮音檔**
    請 AI 幫你壓縮：「請幫我把這個音檔壓縮到 25MB 以下」

    **方法二：分割音檔**
    如果錄音很長，可以請 AI 幫你分割成多個小檔案分別處理
  </Accordion>

  <Accordion title="支援哪些音檔格式？">
    Whisper API 支援以下格式：
    - mp3（最常見）
    - m4a（iPhone 錄音預設格式）
    - wav
    - mp4、mpeg、mpga、webm

    如果你的檔案是其他格式，可以請 AI 幫你轉換。
  </Accordion>

  <Accordion title="可以修改會議紀錄的格式嗎？">
    當然可以！你有幾個選擇：

    1. **修改 Skill**：請 AI 幫你調整 meeting-to-notion Skill 的格式
    2. **使用 Skill Creator**：用 `/skill-creator` 建立一個新的、符合你需求的 Skill
    3. **手動調整**：在 Notion 中直接編輯已經產生的會議紀錄
  </Accordion>

  <Accordion title="我沒有程式背景，真的可以完成這個設定嗎？">
