這個教學會帶你學習如何建立一個自動化流程：只需要提供音檔位置，系統就會自動將音檔轉換成會議紀錄，並儲存到 Notion Database 中。

<Info>
**本教學會使用到的工具：**
- **OpenAI Whisper API** - 語音轉文字
- **Claude** - 整理會議內容
- **Notion MCP Server** - 自動化串接 Notion

請確保你已經準備好這些工具的 API Key。
</Info>

---

## 前置準備：申請必要的 API Key

在開始之前，你需要申請以下 API Key：

### 1. 申請 OpenAI API Key（給 Whisper 使用）

<Steps>
  <Step title="前往 OpenAI 平台">
    前往 [OpenAI Platform](https://platform.openai.com/) 並登入或註冊帳號
  </Step>
  <Step title="進入 API Keys 頁面">
    點擊右上角的個人頭像 → **View API Keys**

    或直接前往：https://platform.openai.com/api-keys
  </Step>
  <Step title="建立新的 API Key">
    1. 點擊 **Create new secret key**
    2. 輸入名稱，例如「Whisper 語音轉文字」
    3. 點擊 **Create secret key**
    4. **立即複製並保存** API Key（只會顯示一次！）
  </Step>
  <Step title="設定付費方式">
    Whisper API 需要付費使用：

    1. 前往 **Settings** → **Billing**
    2. 點擊 **Add payment method**
    3. 新增信用卡資訊

    <Info>
    **費用參考**：Whisper API 費用約為 $0.006/分鐘，一小時的音檔約 $0.36 美元。
    </Info>
  </Step>
</Steps>

<Warning>
**重要提醒**：
- API Key 只會顯示一次，請立即複製保存
- 不要將 API Key 分享給他人或上傳到公開的程式碼庫
- 建議設定用量限制，避免意外產生高額費用
</Warning>

### 2. 設定 Notion Integration

<Steps>
  <Step title="前往 Notion 開發者頁面">
    前往 [Notion Developers](https://www.notion.so/my-integrations) 並登入你的帳號
  </Step>
  <Step title="建立新的 Integration">
    1. 點擊 **New integration**
    2. 輸入名稱，例如「會議紀錄助手」
    3. 選擇要連接的 Workspace
    4. 點擊 **Submit** 建立
  </Step>
  <Step title="複製 API Token">
    建立完成後，複製 **Internal Integration Token**（以 `secret_` 開頭）
  </Step>
  <Step title="授權 Integration 存取頁面">
    1. 開啟你想要存放會議紀錄的 Notion 頁面
    2. 點擊右上角的 **...** 選單
    3. 選擇 **Connections** → **Connect to** → 你剛建立的 Integration
  </Step>
</Steps>

## 建立 Notion 會議紀錄 Database

在開始自動化流程之前，你需要在 Notion 中建立一個專門管理會議紀錄的 Database。

### 步驟 1：建立 Page 並授權 Integration

<Steps>
  <Step title="建立新的 Page">
    在 Notion 中建立一個新的 Page，命名為「會議紀錄」或你喜歡的名稱
  </Step>
  <Step title="授權 Integration 存取">
    1. 點擊頁面右上角的 **...** 選單
    2. 選擇 **Connections**
    3. 點擊 **Connect to** → 選擇你在前置準備中建立的 Integration（例如「會議紀錄助手」）

    <Warning>
    **重要**：必須先完成授權，AI 才能存取這個頁面並建立 Database。
    </Warning>
  </Step>
  <Step title="取得 Page ID">
    複製頁面的網址，網址格式類似：
    ```
    https://www.notion.so/你的工作區/會議紀錄-abc123def456...
    ```

    其中 `abc123def456...` 這串就是 Page ID，請記下來備用。
  </Step>
</Steps>

### 步驟 2：讓 AI 協助建立 Database

當你完成授權後，可以請 AI 在這個 Page 中建立符合格式的 Database。

複製以下提示詞，貼到 Claude 對話框中：

```text
請在我的 Notion 頁面中建立一個會議紀錄 Database。

Page ID：[貼上你的 Page ID]

Database 需要包含以下欄位：
1. 標題（Title）：會議主題
2. 日期（Date）：會議日期
3. 參與者（Multi-select）：參與人員
4. 狀態（Select）：待整理 / 已完成 / 需追蹤
5. 摘要（Text）：會議摘要
6. 待辦事項（Text）：行動項目清單
7. 會議內容（Text）：完整的會議紀錄

請建立這個 Database，並將 Database ID 告訴我。
```

<Tip>
**Database 建立完成後**，AI 會提供 Database ID，請記下來。後續的自動化流程會使用這個 ID 來新增會議紀錄。
</Tip>

### Database 欄位說明

| 欄位名稱 | 類型 | 用途 |
|---------|------|------|
| 會議主題 | Title | Database 的標題欄位，顯示會議名稱 |
| 日期 | Date | 記錄會議舉行的日期 |
| 參與者 | Multi-select | 可選擇多位參與者，方便篩選 |
| 狀態 | Select | 追蹤會議紀錄的處理狀態 |
| 摘要 | Text | 簡短的會議重點摘要 |
| 待辦事項 | Text | 從會議中整理出的行動項目 |
| 會議內容 | Text | 完整的結構化會議紀錄 |

## 快速開始：一鍵建置提示詞

<Note>
**只要複製以下提示詞，貼到 Claude 對話框中，就可以快速完成建置！**
</Note>

### 提示詞一：建立會議紀錄整理 Skill

複製以下內容，貼到 Claude 對話框：

```text
請幫我在專案中建立一個 Skill，用來處理會議錄音並自動儲存到 Notion。

請在 .claude/skills/ 資料夾中建立 meeting-to-notion.md 檔案，內容需要包含：

## Skill 功能
這個 Skill 會執行以下完整流程：
1. 使用 Whisper API 將音檔轉換成逐字稿
2. 整理成結構化的會議紀錄格式
3. 自動將結果儲存到指定的 Notion Database

## 會議紀錄格式
- 會議資訊（日期、參與者）
- 會議摘要（3-5 句話）
- 討論議題和內容
- 關鍵決策
- 待辦事項（使用 checkbox 格式）
- 下次會議建議

## Notion 設定
Database ID：[填入你的 Database ID]

請直接建立這個檔案。
```

### 提示詞二：處理音檔並自動儲存到 Notion

複製以下內容，貼到 Claude 對話框：

```text
請幫我處理會議錄音檔案，並自動儲存到 Notion。

音檔位置：[輸入你的音檔路徑，例如 ~/Downloads/meeting.mp3]

請執行以下步驟：
1. 使用 Whisper API 將音檔轉換成文字
2. 使用 /meeting-to-notion Skill 整理成會議紀錄格式
3. 自動將整理好的會議紀錄儲存到 Notion Database

完成後請告訴我 Notion 頁面的連結。
```

## 建立 Skill：自動化會議紀錄

### Skill 檔案內容

在專案中建立 `.claude/skills/meeting-to-notion.md`：

```markdown
---
description: 將會議音檔轉換成會議紀錄並自動儲存到 Notion
---

請幫我處理會議錄音，並將整理好的會議紀錄儲存到 Notion Database。

## 完整處理流程

### 步驟 1：音檔轉文字
使用 Whisper API 將音檔轉換成逐字稿：
- 讀取指定的音檔
- 使用 OpenAI Whisper API 進行語音辨識
- 語言設定為中文（zh）

### 步驟 2：整理會議紀錄
將逐字稿整理成結構化格式：
- 修正明顯的語音辨識錯誤
- 移除口語贅詞（嗯、啊、那個、然後）
- 提取會議資訊（日期、參與者、主題）

### 步驟 3：儲存到 Notion
自動將會議紀錄儲存到 Notion Database：
- Database ID：[你的 Database ID]
- 填入各欄位資料

## 會議紀錄格式

### 會議資訊
- **日期**：[從內容推測或使用今天日期]
- **參與者**：[列出所有提到的人名]
- **主題**：[會議主要討論主題]

### 會議摘要
[用 3-5 句話總結這場會議的主要內容]

### 討論議題

#### 議題一：[議題名稱]
[討論內容摘要]

#### 議題二：[議題名稱]
[討論內容摘要]

### 關鍵決策
- **決策內容**：[決策說明]
- **負責人**：[負責人]
- **時限**：[截止日期]

### 待辦事項
- [ ] [待辦事項] - @[負責人] - [截止日期]
- [ ] [待辦事項] - @[負責人] - [截止日期]

### 下次會議建議
- [建議討論的議題]

---

## 輸出要求
- 使用繁體中文
- 不確定的內容用 [?] 標記
- 保留專有名詞和人名
- 完成後提供 Notion 頁面連結
```

<Steps>
  <Step title="建立 Notion Database">

  </Step>
  <Step title="確認結果">
    AI 會自動完成語音轉文字、整理會議紀錄、儲存到 Notion，並提供頁面連結讓你確認
  </Step>
</Steps>

## 進階設定：Notion MCP Server

為了讓 AI 能夠直接存取和操作 Notion，建議安裝 Notion MCP Server。

### 安裝步驟

<Steps>
  <Step title="安裝 Notion MCP Server">
    在 Claude 設定中加入 Notion MCP Server：

    ```json
    {
      "mcpServers": {
        "notion": {
          "command": "npx",
          "args": ["-y", "@notionhq/notion-mcp-server"],
          "env": {
            "OPENAPI_MCP_HEADERS": "{\"Authorization\": \"Bearer secret_你的Token\", \"Notion-Version\": \"2022-06-28\"}"
          }
        }
      }
    }
    ```
  </Step>
  <Step title="替換 Token">
    將 `secret_你的Token` 替換成你在前置準備中取得的 Notion Integration Token
  </Step>
  <Step title="重新啟動 Claude">
    設定完成後重新啟動 Claude，讓 MCP Server 生效
  </Step>
</Steps>

<Tip>
安裝 MCP Server 後，AI 就可以直接讀取和寫入 Notion，不需要你手動複製貼上任何內容。
</Tip>

## 常見問題

<AccordionGroup>
  <Accordion title="AI 無法存取 Notion 怎麼辦？">
    請確認以下事項：
    - Notion Integration 已正確建立
    - 目標頁面已授權給 Integration（點擊 ... → Connections）
    - MCP Server 設定中的 Token 正確無誤
    - 已重新啟動 Claude 讓設定生效
  </Accordion>

  <Accordion title="API Key 錯誤怎麼辦？">
    常見錯誤和解決方式：
    - **Invalid API Key**：確認 API Key 正確，沒有多餘的空格
    - **Insufficient quota**：檢查 OpenAI 帳號餘額，可能需要加值
    - **Rate limit exceeded**：等待幾分鐘後再試，或升級帳號方案
  </Accordion>

  <Accordion title="中文辨識不準確？">
    幾個改善建議：
    - 確保錄音環境安靜，減少背景噪音
    - 說話速度適中，發音清晰
    - 如果有專有名詞，可以在 Skill 中請 Claude 協助修正
  </Accordion>

  <Accordion title="音檔太大無法上傳？">
    Whisper API 限制單一檔案最大 25MB。解決方式：
    - 使用 ffmpeg 壓縮音檔：`ffmpeg -i input.mp3 -b:a 64k output.mp3`
    - 將長音檔分割成多個檔案
  </Accordion>

  <Accordion title="支援哪些音檔格式？">
    Whisper API 支援以下格式：
    - mp3, mp4, mpeg, mpga, m4a, wav, webm

    如果你的檔案是其他格式，可以使用 ffmpeg 轉換：
    ```bash
    ffmpeg -i input.ogg output.mp3
    ```
  </Accordion>

  <Accordion title="如何修改 Database 欄位？">
    如果你想要調整 Database 的欄位，可以：
    1. 直接在 Notion 中手動修改 Database 結構
    2. 請 AI 協助修改：「請幫我在 Database 新增一個『會議類型』欄位」
    3. 記得同步更新 Skill 中的格式說明
  </Accordion>
</AccordionGroup>
