這個教學會帶你學習如何將音檔轉換成會議紀錄，並自動整理到 Notion 中。

<Info>
**本教學會使用到的工具：**
- **OpenAI Whisper API** - 語音轉文字
- **Claude** - 整理會議內容
- **Notion** - 儲存會議紀錄

請確保你已經準備好這些工具的 API Key。
</Info>

---

## 前置準備：申請必要的 API Key

在開始之前，你需要申請以下 API Key：

### 1. 申請 OpenAI API Key（給 Whisper 使用）

<Steps>
  <Step title="前往 OpenAI 平台">
    前往 [OpenAI Platform](https://platform.openai.com/) 並登入或註冊帳號
  </Step>
  <Step title="進入 API Keys 頁面">
    點擊右上角的個人頭像 → **View API Keys**

    或直接前往：https://platform.openai.com/api-keys
  </Step>
  <Step title="建立新的 API Key">
    1. 點擊 **Create new secret key**
    2. 輸入名稱，例如「Whisper 語音轉文字」
    3. 點擊 **Create secret key**
    4. **立即複製並保存** API Key（只會顯示一次！）
  </Step>
  <Step title="設定付費方式">
    Whisper API 需要付費使用：

    1. 前往 **Settings** → **Billing**
    2. 點擊 **Add payment method**
    3. 新增信用卡資訊

    <Info>
    **費用參考**：Whisper API 費用約為 $0.006/分鐘，一小時的音檔約 $0.36 美元。
    </Info>
  </Step>
</Steps>

<Warning>
**重要提醒**：
- API Key 只會顯示一次，請立即複製保存
- 不要將 API Key 分享給他人或上傳到公開的程式碼庫
- 建議設定用量限制，避免意外產生高額費用
</Warning>

### 2. 設定 Notion Integration

<Steps>
  <Step title="前往 Notion 開發者頁面">
    前往 [Notion Developers](https://www.notion.so/my-integrations) 並登入你的帳號
  </Step>
  <Step title="建立新的 Integration">
    1. 點擊 **New integration**
    2. 輸入名稱，例如「會議紀錄助手」
    3. 選擇要連接的 Workspace
    4. 點擊 **Submit** 建立
  </Step>
  <Step title="複製 API Token">
    建立完成後，複製 **Internal Integration Token**（以 `secret_` 開頭）
  </Step>
  <Step title="授權 Integration 存取頁面">
    1. 開啟你想要存放會議紀錄的 Notion 頁面
    2. 點擊右上角的 **...** 選單
    3. 選擇 **Connections** → **Connect to** → 你剛建立的 Integration
  </Step>
</Steps>

## 詳細教學：使用 Whisper 轉換音檔

### 步驟 1：安裝必要套件

在終端機中執行：

```bash
pip install openai
```

### 步驟 2：設定 API Key

<Tabs>
  <Tab title="macOS / Linux">
    在 `~/.bashrc` 或 `~/.zshrc` 中加入：

    ```bash
    export OPENAI_API_KEY="sk-你的API金鑰"
    ```

    然後執行：
    ```bash
    source ~/.bashrc  # 或 source ~/.zshrc
    ```
  </Tab>
  <Tab title="Windows">
    在 PowerShell 中設定：

    ```powershell
    [Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-你的API金鑰", "User")
    ```

    需要重新開啟 PowerShell 生效。
  </Tab>
</Tabs>

### 步驟 3：建立轉換腳本

建立 `whisper_transcribe.py` 檔案：

```python
import sys
import os
from openai import OpenAI

def transcribe_audio(audio_path):
    """使用 Whisper API 將音檔轉換成文字"""

    # 檢查檔案是否存在
    if not os.path.exists(audio_path):
        print(f"錯誤：找不到檔案 {audio_path}")
        return None

    # 初始化 OpenAI 客戶端
    client = OpenAI()

    print(f"正在轉換：{audio_path}")
    print("這可能需要幾分鐘，請稍候...")

    # 開啟音檔並進行轉換
    with open(audio_path, "rb") as audio_file:
        transcript = client.audio.transcriptions.create(
            model="whisper-1",
            file=audio_file,
            language="zh",  # 指定中文
            response_format="text"
        )

    # 儲存結果
    output_path = audio_path.rsplit(".", 1)[0] + ".txt"
    with open(output_path, "w", encoding="utf-8") as f:
        f.write(transcript)

    print(f"轉換完成！結果已儲存至：{output_path}")
    return transcript

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("使用方式：python whisper_transcribe.py <音檔路徑>")
        print("範例：python whisper_transcribe.py meeting.mp3")
        sys.exit(1)

    audio_path = sys.argv[1]
    result = transcribe_audio(audio_path)

    if result:
        print("\n--- 轉換結果預覽 ---")
        print(result[:500] + "..." if len(result) > 500 else result)
```

### 步驟 4：執行轉換

```bash
python whisper_transcribe.py your-meeting.mp3
```

轉換完成後，會生成一個 `.txt` 檔案，包含逐字稿內容。

## 整理會議紀錄：建立 Skill

### 建立 Skill 檔案

在專案中建立 `.claude/skills/meeting-transcribe.md`：

```markdown
---
description: 將會議逐字稿整理成結構化的會議紀錄
---

請幫我將會議錄音的逐字稿整理成結構化的會議紀錄。

## 處理步驟

### 1. 修正與潤飾
- 修正明顯的語音辨識錯誤
- 移除口語贅詞（嗯、啊、那個、然後）
- 保持原意，讓文字更通順

### 2. 提取會議資訊
- 會議日期和時間（如果有提到）
- 參與者名單
- 會議主題

### 3. 整理成以下格式

## 📋 會議紀錄

**日期**：[日期]
**參與者**：[參與者列表]
**主題**：[會議主題]

### 會議摘要
[用 3-5 句話總結這場會議的主要內容]

### 討論議題

#### 議題一：[議題名稱]
[討論內容摘要]

#### 議題二：[議題名稱]
[討論內容摘要]

### 關鍵決策
- **決策內容**：[決策說明]
- **負責人**：[負責人]
- **時限**：[截止日期]

### 待辦事項
- [ ] [待辦事項] - @[負責人] - [截止日期]
- [ ] [待辦事項] - @[負責人] - [截止日期]

### 下次會議建議
- [建議討論的議題]

---

## 輸出要求
- 使用繁體中文
- 使用 Notion 支援的 Markdown 格式
- 不確定的內容用 [?] 標記
- 保留專有名詞和人名
```

## 常見問題

<AccordionGroup>
  <Accordion title="API Key 錯誤怎麼辦？">
    常見錯誤和解決方式：
    - **Invalid API Key**：確認 API Key 正確，沒有多餘的空格
    - **Insufficient quota**：檢查 OpenAI 帳號餘額，可能需要加值
    - **Rate limit exceeded**：等待幾分鐘後再試，或升級帳號方案
  </Accordion>

  <Accordion title="中文辨識不準確？">
    幾個改善建議：
    - 確保錄音環境安靜，減少背景噪音
    - 說話速度適中，發音清晰
    - 如果有專有名詞，可以在 Skill 中請 Claude 協助修正
  </Accordion>

  <Accordion title="音檔太大無法上傳？">
    Whisper API 限制單一檔案最大 25MB。解決方式：
    - 使用 ffmpeg 壓縮音檔：`ffmpeg -i input.mp3 -b:a 64k output.mp3`
    - 將長音檔分割成多個檔案
  </Accordion>

  <Accordion title="支援哪些音檔格式？">
    Whisper API 支援以下格式：
    - mp3, mp4, mpeg, mpga, m4a, wav, webm

    如果你的檔案是其他格式，可以使用 ffmpeg 轉換：
    ```bash
    ffmpeg -i input.ogg output.mp3
    ```
  </Accordion>
</AccordionGroup>
